# 语言适配规则

ASD-STE100 约束英文。以下规则用于提高中文和其他语言技术文本的清晰度。
这些规则是本仓库的编辑指南，不是适用于这些语言的正式 STE 规则。

默认使用中文。用户明确选择其他语言时，保留用户选择的语言。
不要仅为了应用英文词数限制而翻译产物。

## 中文

- 一句表达一个主要判断。说明条件后，再说明动作或结果。
- 用明确的主语和动词。多个对象同时出现时，少用“它”“这个”。
- 首次出现时解释术语。同一概念使用同一名称；保留 API、变量、公式及单位。
- 删除不影响技术含义的比喻、口号和对话回顾。
- 将多个因果关系拆成相邻短句。保留“可能”“仅在”等限定条件。
- 超过约 40 个汉字的句子应人工检查是否需要拆分。这是检查提示，不是标准限值。
- 不用空格分词结果宣称中文满足英文 20/25 词规则。

对于混合语言文本，保留技术标识符。读者需要解释时，使用正文语言说明标识符的含义。

## 解说和字幕

解说使用适合口述的句子。不要朗读一组未解释的缩写。
如果解说已说明含义，屏幕标签可以使用短语。
字幕应在短语边界处换行。不要拆开数值与单位，也不要以改变关系的方式拆开条件与结果。
每条字幕的显示时间应满足目标播放速度下的阅读需要。
修改文本后重新检查音频时间，修订后的字幕不能继续使用旧音频。
