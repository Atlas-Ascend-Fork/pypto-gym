# 来源和适用范围

以下主要来源已在 2026-10-09 检查：

- [ASD-STE100 官方网站](https://www.asd-ste100.org/)：提供规范获取方式和维护信息。
- [STE 简介](https://www.asd-ste100.org/about_STE.html)：说明受控语言、写作规则和词典。
- [第 9 版规范](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)：提供权威规则和词典。
- [STE 工具](https://asd-ste100.org/STEsoftware.html)：说明自动检查的限制。

本技能包含适用于实际写作流程的原创说明，不复制规范或完整词典。
本技能列出的英文约束只是规则子集。正式合规检查必须使用适用的完整规范。

以下内容用于一般技术沟通，不属于 ASD 官方规则：

- 消除对原始会话的依赖，同时保留必要的来源信息。
- 保留测量范围，并区分证据与假设。
- 对中文采用本地编辑规则，不宣称符合英文规范。
- 修改多媒体文本后，保持文本与音频一致。

本技能不依赖特定算子、仓库、组织或模型。
