# 性能原则在 PyPTO-Pro + A5 上的落地

适用范围：**PyPTO-Pro 框架 + 本仓的算子开发流程 + Ascend A5（950PR/950DT）芯片**。
换框架或换芯片时新增一份同级文件，不要改写本文件或原则。

> 本文件是 [`kernel-core-principles.md`](kernel-core-principles.md) 的落地层。原则对芯片、
> 框架、工具链与流程都不作假设，因此不含具体对象与数值；本文件把这些补上——术语对应、
> 阈值、自检清单、取舍裁决、以及结论写到哪里。原则稳定，本文件随框架与实测更新。
>
> **依赖是单向的**：本文件引用原则，原则不引用本文件、也不提及任何平台、工具或 skill。
> 换框架或换芯片时改本文件，不改原则。

## 1. 平台与框架映射

原则里的抽象术语在本平台的具体对象：

| 原则中的说法 | 本平台 / 本框架 |
|---|---|
| 主存 | GM（HBM） |
| 片上存储层级（`T1` 逐空间列举） | UB、L1、L0A、L0B、L0C，各自独立寻址、独立限容 |
| 片上累加器（`Q2`） | L0C |
| 轮转 buffer（`P2`） | `make_tile_group` + `auto_mutex`；`make_tile` 仅限单次 scratch |
| 有效形状 / 掩码（`T4`） | `pl.set_validshape`、VF 的 `update_mask` |
| 执行流水（`B2`/`P1`） | MTE1/MTE2/MTE3、Cube(MAC)、Vector、Scalar、FixPipe |
| Vector 占比证据（`V1`） | msprof 的 `aiv_vec_ratio` / `aic_mac_ratio` 等 pipe ratio |
| 布局变换（`Q4`） | ND ↔ NZ、`order=` 形式的转置搬入 |
| 单趟元素数（`T3`） | 设计文档里记作 `elements_per_pass` |
| 分核数 | `block_dim`，上限随 SKU 变化，用 `get_platform_info()` 取，不要硬编码 |

A5 上已实测的平台常数（带宽、MTE2 填充率、Cube 定律等）在
`pypto-pro-op-kb/constraints/arch-a5.md`，标定方法见 `pypto-pro-roofline-calibrate`。

## 2. 自检清单（`G`）

调优收尾时逐项自查，当「还有哪里没看」的清单用。没测过的记 `unknown`——它是合规取值，
不是缺陷（`M1`）。不要求产出专门的门禁文件，写进你本来就有的报告即可。

| 编号 | 检查项 | 参考判据 | 证据来源 |
|---|---|---|---|
| `G1` | 正确性前置（其余项的前提） | 精度用例全部通过 | 测试日志 |
| `G2` | 无标量受限 | 标量流水占比 ≤ 0.5 × 最大流水占比；循环内零除法 / 取模（`P4`） | msprof pipe ratio + 源码扫描 |
| `G3` | 流水重叠 | `max(pipe_ratio) ≥ 0.8`；否则说明未被计量的绑定因素（同步、依赖链） | msprof pipe ratio |
| `G4` | 多核均衡 | `η_tail ≥ 0.9`（`P3`）；有分核时间线时核间离散度 ≤ 10% | `block_dim` + 分核数据 |
| `G5` | 流量 | `A ≤ 1.1`（`B5`） | GM 读写字节计数 |
| `G6` | Roofline 终态 | `t_meas ≤ 1.25 × t_est`（`B1`–`B3`）；否则列出剩余差距及其归因 | 模型 + 实测 |

**排障顺序**：`G1` → `G2` → `G3` → `G4` → `G5` → `G6`。这个顺序有实际原因——前项未通过时，
后项的测量会被它污染，据此归因往往指向错误的方向。

**这些阈值是工程约定，不是物理常数**：`0.8` / `0.9` / `1.1` / `1.25` / `0.5` 都是「到这里
就不必再抠」的界，可随平台与算子形态调整；调整时在报告里写明新值与理由。原则本身不含阈值。

## 3. 已知取舍的裁决

下列取舍已经有过结论，可直接采用，不必每次重新辩论。

| 取舍 | 裁决 |
|---|---|
| 大 tile（`B5`/`Q3`）↔ 双缓冲占用翻倍（`P2`） | 保留双缓冲，在剩余容量内取最大 tile。 |
| 少而大的任务（`B5`）↔ 多核均衡（`P3`） | 先满足 `η_tail`，再在其内最大化 tile。 |
| 减 GM 字节（`B5`）↔ 保持 CV 错拍（`X1`） | 以 profile 判定的绑定资源为准（`B4`）；未证明 GM 为绑定资源时保持错拍。 |
| 深度融合（`B5`）↔ 片上容量（`T1`） | 拆为多趟片上数据遍历，每趟复核 `T1` 与 `A`。 |
| 重读小张量省不省（`B5`）↔ 实际代价 | 先查重读工作集是否驻 L2：驻 L2 时每字节远低于 DRAM 价，按 DRAM 计价会高估、从而误导方向（见 `arch-a5.md`）。 |
