# 技术卡片 recurrence-03：窄精度副本精确全零时跳过对应矩阵乘

低精度副本可能全零，但原始宽精度值仍非零。
若矩阵乘只消费全零副本，且浮点语义允许，可省去该乘法。
其他计算仍可能依赖宽精度值，因此必须保留宽精度数据流。
本卡将这种改写称为“消乘”。

## 何时用（诊断特征）

采用前逐项验证：

- [ ] 流程同时保留宽精度映射 P_high 和供部分消费者使用的窄副本 P_low。
- [ ] 消费者实际读取的完整 P_low 精确全零，不能只检查部分分片或近似范数。
- [ ] 被跳过矩阵乘的其他操作数及累加输入有限，不含会改变零乘语义的 NaN 或 Inf。
- [ ] 原数值合同允许跳过矩阵乘，并已覆盖舍入、带符号零和异常传播。
- [ ] 实测零命中率足以摊销判定、标志合并、同步和分支成本。

该机会由数据表示与消费关系决定。例如反复衰减的宽精度映射可能在窄化后为零，但宽精度
残余仍参与其他更新；必须按消费者逐项判断可删除的工作。

## 何时不适用

- 只知道范数很小、部分分片为零，或以任意 epsilon 阈值代替精确零判定。
- 零乘的另一操作数含 NaN/Inf：`0 * Inf` 或 `0 * NaN` 不能按普通零贡献删除。
- 带符号零、舍入、累加或异常传播的合同不允许省略，或尚未验证实际低精度执行行为。
- 以窄副本全零为理由清空宽精度数据，或把本轮判定永久用于后续迭代。

## 原理

`P_high` 是宽精度映射。`P_low=cast(P_high)` 是消费者实际读取的低精度副本。
零判定必须检查完整的 `P_low`，不能用 `P_high` 的近似范数代替。

当 `P_low` 全零，且其他数值条件满足时，才可省略其乘法贡献。
继续执行 `P_high` 的更新、宽精度状态传播和其他输出计算。
若原乘法带累加输入，还需保留累加值，不能直接将结果设为零。

精确实数中的零乘恒等式不足以证明浮点执行等价；cast 位置、特殊值和已存在的舍入合同
需要共同验证。未来变换若会放大宽残余，重新生成窄副本并重新判定。

## 怎么改（改写前 / 改写后）

以下为**结构示意**，以不带累加输入的矩阵乘为例；省略布局、flag/sync 和特殊值检测实现：

```text
改写前：
  P_low = cast(P_high)
  R = matmul(P_low, X_low)
  继续执行宽精度更新及 R 的消费者
改写后：
  生产者生成 P_low 时记录局部 any_nonzero 和 nonfinite
  合并全部分片并发布完整判定
  消费者确认判定可见，且被省略乘法的其他数值前提满足
  若 P_low 完整有限且精确全零：
    省略该 matmul，按原合同产生 R 的零贡献
  否则执行原 matmul
  两条路径均保留宽精度更新，并完整产生后续读取的结果
```

可在原类型转换过程中计算局部标志，避免再次扫描操作数。
必须合并全部分片的标志，不能根据单个分片进入零分支。

省略乘法后，重新检查剩余计算的依赖关系。
若两项计算已无依赖，可评估交错执行。
零判定本身不能证明两项计算独立。

## 性能与验证指标

- 零命中率、实际减少的矩阵乘、flag 合并与同步成本，以及删除依赖后的重叠窗口。
- 完整调用在全零、全非零和混合命中输入下的成本，尤其检查低命中率退化。
- 覆盖窄副本全零而宽值非零、仅一个分片非零、非零初始状态和跨轮残余放大。
- 按接口的特殊值合同检查另一操作数非有限、累加输入和带符号零；条件不足时走原路径。
- 检查多次调用、工作区污染、标志可见性和各分支完整写入。

现有验证同时覆盖零分支、宽状态保留和独立计算的重叠。
验证没有“跳过对应矩阵乘”的单因素性能对照。
零分支命中率取决于输入，不能将现有收益作为其他流程的性能承诺。

## 技术限制与风险

- 窄操作数全零不代表宽残余无效；每轮检查实际消费者的副本，不能按经验丢弃宽路径。
- 省略乘法不应绕开仍有语义作用的 cast、校验或输出；数值范围仍需全链路审计。
- 标志可能跨核/缓存发布，核内 mutex 不自动保证跨任务可见。
- 不等次数的 buffer 轮转可能破坏地址对应；共享地址时核对共享计数器和 buffer 的生命周期。
