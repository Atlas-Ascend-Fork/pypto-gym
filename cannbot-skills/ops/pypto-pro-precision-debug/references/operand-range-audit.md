# 窄操作数全链路审计

适用于合法输入出现 Inf/NaN、把 BF16/FP32 操作数窄化，或修复第一个 cast 后仍失败的情形。
先区分**可表示范围、舍入误差和算法稳定性**，保持原 Golden、合法输入范围和 comparator。

## 追到实际 consumer

沿实际数据流列出输入预处理、中间张量、矩阵乘操作数、累加/归约结果、输出及各分派路径的
dtype、cast 位置与数值范围。有状态接口还需覆盖外部状态和传播中间量。
检查声明和生成物；变量名中的 `half`/`f16` 不代表实际 dtype。
FP32 accumulator 不能修复已成为 Inf 的低精度操作数，外部接口 BF16 也不保证内部 FP16 合法。

BF16 与 FP16 同为 16 位，但指数范围不同。例如合法 BF16 数值 `131072` 乘 `0.5` 得到
`65536`，转 FP16 会溢出。另测首个 cast 可表示、随后缩放或累加结果溢出的情况；
只修第一个窄化点会漏掉后续 consumer 或其他分派路径。

采取保留足够范围的操作数路径，或在**完整受影响路径**提供可证明安全的回退。改用 BF16
仍会改变尾数舍入，必须重新验证有限值误差。有限边界测试不能证明所有合法输入安全；需要
范围界限或保守路径时明确条件，不能偷偷收窄接口支持范围。

## 最小诊断矩阵

| 维度 | 必查内容 |
|---|---|
| 范围 | 正/负大输入及缩放参数；首个 cast 可表示但后续变换或累加溢出 |
| 分派 | 覆盖会改变数值范围的输入变换、参数边界、专用路径与 fallback |
| 布局 | 非对称数据及独立布局参考；相同 shape 不能单独识别转置或轴映射错误 |
| 状态（接口包含时） | 非零初始状态、连续多次调用的中间及最终状态，对照等价完整计算 |
| 分块（实现包含时） | 相邻块使用不同数据，独立验证局部索引、mask、边界与跨块依赖 |
| 舍入 | 记录每个实际 cast 的 dtype 和 rounding，使用原容差对拍 |

分块参数改动需核对实际计算边界、相关索引和消费者，不能只改参数或 tile 名。
窄副本精确为零不意味着宽原值为零；两种精度的值均有消费者时，分别检查其数值贡献。

缓冲复用可用浮点 GM `empty` 污染、保留旧返回值及多次相同输入调用检查遗漏写入、别名和
输入修改；它只覆盖实际污染到的分配，不证明 UB/L1 初始化或排除同步竞争。错误每次相同
也不能单独排除固定调度下的同步缺陷。
